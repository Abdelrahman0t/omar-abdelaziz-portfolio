# Luxe Spaces Studio

Create a world-class, award-worthy portfolio website for a luxury interior design studio. The website should feel like an editorial magazine combined with a premium architecture studio. Every section must be thoughtfully designed with a unique layout, elegant spacing, and premium interactions. Avoid generic SaaS layouts or template-style sections. The website should immediately communicate luxury, trust, creativity, and attention to detail.

OVERALL DESIGN DIRECTION

Style:

- Minimal luxury

- Editorial layout

- Scandinavian + Modern + Contemporary aesthetic

- Premium architecture studio feel

- Inspired by high-end brands rather than typical interior design websites

Visual Tone:

- Calm

- Sophisticated

- Spacious

- Expensive

- Timeless

- Elegant

- Premium

Color Palette:

Primary Background:

#F3EFEA

#1E1E1E

Accent:

Warm bronze (#A67C52)

Use natural wood textures, stone, linen, marble, soft shadows, and subtle gradients.

Typography

Heading:

Elegant modern serif

Body:

Clean geometric sans serif

Very large headings with generous spacing.

Use lots of whitespace.

Images

Images should dominate the layout.

Use oversized project photography.

Large edge-to-edge photography.

Editorial cropping.

Rounded corners only 16px.

Large image masks.

Use layered image compositions.

Micro Interactions

• Smooth fade animations

• Images slowly zoom on hover

• Buttons gently lift

• Project cards expand

• Smooth scrolling

• Floating navigation

• Animated counters

• Elegant page transitions

• Sticky CTA

• Mouse parallax for hero imagery

UI DETAILS

======================================

Buttons:

- Rounded pills

- Soft shadows

- Bronze hover glow

Cards:

- 24px radius

- Glassmorphism where appropriate

- Large padding

- Elegant shadows

Spacing:

- Very generous

- 120–180px between sections

Animations:

- Framer Motion style

- Smooth easing

- Fade

- Scale

- Slide

- Staggered reveals

Icons:

Minimal line icons.

Forms:

Premium floating labels.

Portfolio cards:

Image first.

Content second.

Hover:

Image scale 1.08

Responsive:

Desktop, Tablet, Mobile.

Desktop should feel like an editorial magazine.

Do NOT generate a template-looking website.

Every section must have its own unique composition and visual identity.

The final design should be visually comparable to websites featured on Awwwards and should resemble the quality of luxury studios such as Kelly Wearstler, Studio McGee, Norm Architects, Yabu Pushelberg, Vincent Van Duysen, and Foster + Partners. Prioritize storytelling through imagery, exceptional typography, refined motion, and meticulous spacing over decorative effects.
